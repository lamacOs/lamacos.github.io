GitHub Personal Access Token

Trag hier deinen GitHub-PAT ein. Er wird in LocalStorage gespeichert (nur lokal in deinem Browser, nie übertragen). Wird benötigt, um deine Site direkt ins Repo lamacOs/lamacos.github.io zu veröffentlichen.

Hinweis: Der GitHub-PAT wird bevorzugt aus Firebase Realtime DB unter /patkey geladen — so muss jeder User nichts eintragen. Fallback: hier eintragen.

So erstellst du einen PAT: GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token → Scope repo aktivieren → Generate. Token kopieren und in Firebase unter /patkey ablegen.

Veröffentlichen

Deine Site wird als cw/{siteName}/index.html im Repo lamacOs/lamacos.github.io gespeichert und ist nach ~30 Sekunden unter https://lamachub.de/cw/{siteName}/ erreichbar.
