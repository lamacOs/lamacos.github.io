Website Einstellungen

GitHub Personal Access Token

Gib hier deinen GitHub-PAT ein. Er wird lokal gespeichert. Wird benötigt, um Websites direkt in das Repository lamacOs/lamacos.github.io zu veröffentlichen.

Hinweis: Der PAT kann auch automatisch aus Firebase Realtime DB unter /patkey geladen werden. Fallback: hier manuell eintragen.

Website veröffentlichen

Deine Site wird als cw/{siteName}/index.html im Repo lamacOs/lamacos.github.io gespeichert und ist in wenigen Sekunden unter https://lamachub.de/cw/{siteName}/ erreichbar.
