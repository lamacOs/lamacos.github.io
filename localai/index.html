Hallo! Ich bin eine lokale KI. Sobald du oben auf "Modell laden" klickst, werden die Gewichte des Modells in deinen lokalen Browser-Speicher geladen. Danach berechnet meine Antworten ausschließlich deine eigene Grafikkarte (WebGPU) – ganz ohne externe Server oder API-Kosten!

Erfordert einen WebGPU-fähigen Browser (Chrome, Edge, Brave, Arc, Safari 18+). Daten verlassen niemals dein Gerät.
