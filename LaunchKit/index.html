Einführung

LaunchKit ist eine Plattform, mit der du digitale Produkte – von Software bis zu Open-Source-Projekten – professionell präsentierst, versionierst und analysierst.

Du brauchst kein eigenes Marketing-Frontend, kein manuelles Versionieren und keine eigene Download-Infrastruktur. LaunchKit liefert dir alles ab Tag 1.

Produkt erstellen

  1. Konto registrieren und im Dashboard anmelden.
  2. Auf Neues Produkt klicken.
  3. Den mehrstufigen Assistenten durchlaufen.
  4. Veröffentlichen – deine Produktseite ist sofort erreichbar.

Veröffentlichen

Im letzten Schritt des Assistenten entscheidest du, ob dein Produkt sofort live geht oder als Draft zur späteren Bearbeitung gespeichert wird.

Versionen

Verwalte mehrere Versionen pro Produkt – Stable, Beta oder Preview. Jede Version hat eigene Download-URLs, Release-Notes und Statistiken.

POST /api/products/{id}/versions
{ "version": "2.5.0", "channel": "stable", "file": "...", "notes": ["..."] }

Changelog

Strukturierte Release-Notes werden automatisch in der Produktseite ausgespielt.

Screenshots & Medien

Optimale Größe: 1600 × 1000 px. Unterstützte Formate: PNG, JPG, WebP.

Analytics

Aufrufe, Downloads, beliebteste Versionen, Aufrufe pro Tag und Downloadraten.

Eigene Domain

Mit dem Pro-Plan verbindest du eine eigene Domain. Eine ausführliche Anleitung zu DNS-Einträgen findest du im Dashboard.

API

REST-API mit OAuth2-Bearer-Tokens unter /api/v1.

curl -H "Authorization: Bearer $LK_TOKEN" \
  https://api.launchkit.dev/api/v1/products/minecraft-tool-x

Webhooks

Konfiguriere Webhooks für neue Releases, Downloads oder Updates.
