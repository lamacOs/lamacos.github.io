Über diese Anwendung

BOOST Control ist eine eigenständige Single-Page-Anwendung zur vollständigen Steuerung eines LEGO® BOOST Move Hub (88006) über die Web Bluetooth API und das LEGO Wireless Protocol (LWP3). Es werden ausschließlich HTML5, CSS3 und Vanilla-JavaScript verwendet — keine Frameworks, Bibliotheken oder externen Ressourcen. LEGO® ist eine Marke der LEGO Group, die diese Anwendung weder unterstützt noch autorisiert.

Version 1.0.0 · Läuft vollständig lokal im Browser.

Web Bluetooth nicht verfügbar

Dein Browser unterstützt die Web Bluetooth API nicht oder sie ist deaktiviert. Nutze z.B. Google Chrome oder Microsoft Edge auf Desktop oder Android, über HTTPS oder localhost.
